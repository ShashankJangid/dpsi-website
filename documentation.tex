\section{Project Overview \& Institutional Background}

Delhi Public School Indirapuram (Est. 2003), functioning under the aegis of the \textbf{DPS Society, New Delhi}, is one of India's premier K-12 educational institutions. Situated in Ghaziabad, Uttar Pradesh, the school caters to over 6,000+ students with a legacy of 100\% CBSE Board examination pass records, state-of-the-art AI \& Robotics infrastructure, and international awards including the \textbf{British Council International Dimension in Schools Award}.

\subsection{Key Institutional Parameters}
\begin{itemize}[leftmargin=*]
    \item \textbf{CBSE Affiliation Number:} 2130647 | \textbf{School Code:} 60287
    \item \textbf{Campus Location:} 526/1 Ahinsa Khand-II, Indirapuram, Ghaziabad, UP 201014
    \item \textbf{Key Highlights:} 50+ GPS-enabled AC buses, Olympic-size aquatic complex, AI \& Robotics Innovation Lab with humanoid kits and 3D printing, 100\% CBSE Class X \& XII results with top score 99.4\%.
\end{itemize}

\subsection{Core Website Project Objectives}
\begin{enumerate}
    \item \textbf{Modern High-Aesthetic Web Platform:} Deliver a sleek, mobile-first web portal with rich emerald-to-indigo gradient themes, glassmorphic UI cards, dark mode toggle, and smooth 60FPS Framer Motion micro-animations.
    \item \textbf{Interactive Voice AI Assistant:} Integrate an autonomous conversational DPSI AI assistant supporting Hold-to-Talk speech recognition, natural Indian English voice responses (\texttt{en-IN}), and direct CTA action buttons (Call, Email, Open Portals).
    \item \textbf{Unblocked Hero Banner with Typewriter Bar:} Provide a full 100\% natural color campus image slider operating seamlessly below a separate real-time Typewriter backspacing/rewriting announcement bar.
    \item \textbf{Smooth Anchor Navigation Engine:} Implement global offset hash-scrolling for instant navigation to sections like Curriculum, Departments, Results, Leadership, and Timeline.
\end{enumerate}

\subsection{Deep-Dive Specification of Core Technologies}

\subsubsection{React 18 \& TypeScript Engine}
\begin{itemize}
    \item \textbf{Why Chosen:} React 18's virtual DOM diffing guarantees fast UI updates, while TypeScript enforces strict compile-time type safety across all components.
    \item \textbf{What It Powers:} Powers component lifecycle, state hooks in \texttt{AIChatWidget.tsx}, slide indexing in \texttt{HeroSection.tsx}, and client-side routing in \texttt{App.tsx}.
\end{itemize}

\subsubsection{Framer Motion Animation Suite}
\begin{itemize}
    \item \textbf{Why Chosen:} Provides 60FPS GPU-accelerated motion without layout thrashing.
    \item \textbf{What It Powers:} Powers the 1.4s hero slider crossfade dissolve (\texttt{AnimatePresence}), the right-edge slide-out social media drawer (\texttt{FloatingSocials.tsx}), and modal open/close animations.
\end{itemize}

\subsubsection{Web Speech API (Audio \& Voice Engine)}
\begin{itemize}
    \item \textbf{Why Chosen:} Delivers native browser speech recognition and natural text-to-speech without external API fees or latency.
    \item \textbf{What It Powers:} Enables Hold-to-Talk microphone input (\texttt{window.SpeechRecognition}) and reads AI responses once using preferred Indian English voices (\texttt{window.speechSynthesis.getVoices()}).
\end{itemize}

\subsubsection{Recharts Interactive Analytics}
\begin{itemize}
    \item \textbf{Why Chosen:} High-performance SVG-based rendering optimized for responsive React containers.
    \item \textbf{What It Powers:} Renders the 5-year CBSE Pass Rate \& Distinction trend bar chart and Class 11 Student Stream Distribution pie chart in \texttt{src/pages/Academics.tsx}.
\end{itemize}

\section{Complete Page-by-Page Module Breakdown}

The application consists of 11 fully developed pages and interactive modules:

\subsection{Home Page (\texttt{src/pages/Home.tsx} \& \texttt{src/sections/HeroSection.tsx})}
\begin{itemize}
    \item \textbf{Top Announcement Bar:} Houses a responsive Typewriter engine that types announcements character-by-character (40ms), pauses (2600ms), backspaces (20ms), and transitions to the next topic.
    \item \textbf{100\% Unblocked Hero Slider:} Displays high-resolution campus imagery below the text bar with a 1.4s smooth crossfade dissolve transition.
    \item \textbf{Welcome Overview \& Quick Stats:} Showcases student strength, faculty count, affiliation details, and quick link CTA buttons (\texttt{Apply Now}, \texttt{Explore Campus}).
\end{itemize}

\subsection{About Us Page (\texttt{src/pages/About.tsx})}
\begin{itemize}
    \item \textbf{Vision \& Mission Statements (\texttt{\#vision}):} Clear institutional roadmap focusing on global citizenship, academic rigor, and moral integrity.
    \item \textbf{Core Values:} Interactive cards detailing Excellence, Integrity, Inclusivity, Innovation, and Resilience.
    \item \textbf{School Leadership (\texttt{\#leadership}):} Profile cards for Mr. V.K. Shunglu (Chairman), Ms. Santosh Bansal (Pro-Vice Chairperson), and Ms. Priya Elizabeth John (Principal).
    \item \textbf{2003--2026 History Timeline (\texttt{\#timeline}):} Chronological milestone timeline tracking school foundation, CBSE affiliation, sports complex, digital upgrade, AI lab, and global awards.
\end{itemize}

\subsection{Academics Page (\texttt{src/pages/Academics.tsx})}
\begin{itemize}
    \item \textbf{CBSE Curriculum Framework (\texttt{\#curriculum}):} Comprehensive breakdown of primary, middle, and senior secondary pedagogy.
    \item \textbf{Academic Departments (\texttt{\#departments}):} 6 specialized cards detailing Science (PCM/PCB/Biotech), Mathematics, Languages, Arts \& Humanities, Computer Science/AI, and Physical Education.
    \item \textbf{Board Examination Analytics (\texttt{\#results}):} Interactive Recharts bar graph displaying 5-year CBSE pass rate (99.9\%) and distinction percentage (72\%), alongside a stream distribution pie chart.

\subsection{Admissions Page (\texttt{src/pages/Admissions.tsx})}

\section{Build \& Deployment Instructions}

\subsection{Local Development \& Verification Commands}
\begin{lstlisting}[language=bash]
# 1. Install dependencies
npm install

# 2. Run TypeScript type checks
npm run check

# 3. Run ESLint checks
npm run lint

# 4. Build production static bundle
npm run build

# 5. Preview local production bundle
npm run preview
\end{lstlisting}

\subsection{Vercel Edge Network Deployment}
The codebase is configured for automated push-to-deploy on GitHub branch \texttt{main}:
\begin{lstlisting}[language=bash]
git add .
git commit -m "Production update"
git push origin main
\end{lstlisting}

Or manual production deployment via Vercel CLI:
\begin{lstlisting}[language=bash]
npx --yes vercel deploy --yes --prod
\end{lstlisting}
